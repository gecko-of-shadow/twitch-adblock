## a) Risks in each PR

### PR #10 (30 files, +712 / -9)

Behaviour changes:
1. `src/general-background.js`: `applyGeneralState` now runs through a promise queue, one run at a time. `refreshLists` also calls `applyGeneralState()` again after each refresh.
   - I checked for a deadlock: `refreshLists` is not called from inside the queue, so it cannot wait on itself.
   - A risk remains: the queue only orders apply runs against each other. A refresh can still write rules while an apply is running. The re-apply after the refresh limits the effect, but the overlap is not removed. UNVERIFIED in a real Chrome.
2. `src/youtube.js` (3 hunks):
   - `requestUrl` accepts a `URL` object.
   - `startedVideoId` now follows the video that is playing, and is cleared on `yt-navigate-start` to a different `v=`.
   - The fetch hook no longer re-sends a request that failed on the network. That also means an aborted fetch is no longer re-sent, which is better.
   - Small new edge: if our own rewritten request is accepted by the rewrite step but then rejected by `fetch` itself, there is no fallback any more. This only applies with the extra fetch hooks on, which are off by default under the uBO layer.
3. `src/popup.html`: `#brand-icon` `border-radius` changes from 8px to 50%. Cosmetic only.
4. All 9 icon PNGs are replaced at the same names and sizes (a green gecko with an amber eye). The gate's REQUIRED icon list still passes.

Locked playback files:
- The gate's diff lock (`PLAYBACK_FILES`, gate lines 113-116) covers only `src/vendor/video-swap-new.user.js` and `src/kick.js`. Neither is changed.
- **`src/youtube.js` is changed.** The gate only checks that it has no `chrome.*` calls (section 4), and it passes.
- The owner's rules describe "the Twitch/YouTube playback code" as locked. Whether `src/youtube.js` counts is the owner's call. #10's change there is small and has tests (`test/youtube-sim.test.js`), but it is a change to YouTube playback code.

Permissions: `manifest.json` is unchanged (`git diff aea6f6d origin/claude/hopeful-gauss-c1a9cx -- manifest.json` is empty). No new permissions, host permissions or content-script matches.

Tests weakened or removed: none. The only removed line under `test/` is a comment in `test/youtube-decoy-nav.test.js`, which now explains the new isolation. No assertion was removed.

Other things to know:
