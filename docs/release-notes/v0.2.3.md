## Install (step by step)

### 1. Open this release page
<img src="https://raw.githubusercontent.com/gecko-of-shadow/twitch-adblock/main/docs/cards-release/install/01-open-github.png" width="800" alt="Step 1: Open the release page.">

### 2. Download the zip
<img src="https://raw.githubusercontent.com/gecko-of-shadow/twitch-adblock/main/docs/cards-release/install/02-download-zip.png" width="800" alt="Step 2: Download the zip under Assets.">

Scroll to **Assets** below and download `twitch-adblock-0.2.3.zip`.

### 3. Unzip the folder
<img src="https://raw.githubusercontent.com/gecko-of-shadow/twitch-adblock/main/docs/cards-release/install/03-unzip.png" width="800" alt="Step 3: Unzip and keep the folder.">

Windows: right-click → **Extract All…** · Mac: double-click the zip. Keep the folder — Chrome needs it.

### 4. Open Chrome Extensions
<img src="https://raw.githubusercontent.com/gecko-of-shadow/twitch-adblock/main/docs/cards-release/install/04-extensions.png" width="800" alt="Step 4: chrome://extensions and Developer mode.">

Go to `chrome://extensions` and turn on **Developer mode** (top right).

### 5. Load unpacked
<img src="https://raw.githubusercontent.com/gecko-of-shadow/twitch-adblock/main/docs/cards-release/install/05-load-unpacked.png" width="800" alt="Step 5: Load unpacked and pick the folder with manifest.json.">

Click **Load unpacked** and pick the unzipped folder (the one with `manifest.json`). You should see the gecko icon.

Turn off other Twitch or YouTube ad blockers while this is loaded.

### 6. Debug (optional)
<img src="https://raw.githubusercontent.com/gecko-of-shadow/twitch-adblock/main/docs/cards-release/install/06-debug.png" width="800" alt="Step 6: Debug starts off; turn on only if you need a log.">

Debug starts **OFF**. For normal watching, leave it off.

If something looks wrong: open the gecko popup → turn Debug **ON** → **Copy debug** → paste into a GitHub issue. Turn it **OFF** when you are done. Nothing is sent automatically.
