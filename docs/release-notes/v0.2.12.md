## What this beta adds

On ordinary websites:

- Many known ad servers are blocked, using a packed list (trimmed EasyList, EasyPrivacy, Peter Lowe’s list, and a malware-host list). Those four lists were packed again for this beta. The full uBlock stack was not added. Credit: The EasyList authors.
- Leftover ad boxes are hidden when the page can spare them. The hide stylesheet is web-accessible so the page can load it. Some empty spots and some ads can still show. This does not block every ad.
- On IMDb, the sponsored billboard is hidden, including the large name-page slot, “Sponsored Content,” and the bottom sponsored strip. Posters stay. That slot lives on IMDb itself. Amazon’s ad host was already blocked. Twitch, YouTube, and Kick playback are unchanged.
- Also blocked on ordinary sites: facebook.net, imasdk.googleapis.com, and fundingchoicesmessages.google.com. YouTube and Kick frames stay allowed. Twitch video hosts stay allowed. Amazon’s ad host is not force-allowed on Twitch pages.
- General blocking starts **on**.
- The popup has a master on/off switch. It does not turn Twitch, YouTube, or Kick playback handling off.
- **Allow this page** lets the open ordinary site through.
- **Update lists** is on the popup. In this beta it only remembers that you asked. It does not download a new list yet. The lists in the zip are the ones that run. Nothing fetches on its own in the background.

Twitch, YouTube (including Music, Kids, and embeds), and Kick video addresses stay out of the general block list.

On Twitch, the Browse directory hides the top banner slot and the in-grid Ad cards. The player is not rewritten. Amazon’s ad host is no longer let through on those pages. gql and the video hosts stay allowed. Some ads can still show. This does not block every ad.

YouTube in this zip includes the black-spinner fix from the stable line, and search results drop sponsored cards the same way Home does. A later playback policy is cleared the same way as the first one. Some starts still sat on a black loading screen after that, with the length already showing and the player already trying to play, and no picture data yet. This beta also clears the video start-buffer target in the playback response, and turns off the server start-buffer switch, including when that switch’s policies arrive as a list. The video address stays. A “Blocking ads” chip shows once per video for about 8 seconds. That chip is not the black spinner. YouTube’s own “Experiencing interruptions?” toast is removed when it appears, including when YouTube puts it back. Other toasts stay. Removing that toast does not start the picture by itself.

This zip also includes the Kick in-player ad try from beta v0.2.4: when Kick’s IVS player can jump back to the live stream, short ad breaks are skipped without muting or hiding the video. The general list still does not run on kick.com.

Debug still starts off. Copy debug still works on Twitch and YouTube, and the copied log names this build (0.2.12) instead of always saying 0.2.3.

Chrome may warn that this can block content on pages. Hiding leftover boxes also runs on ordinary sites, so Chrome may say it can change those pages. It does not run that hide on Twitch, YouTube, or Kick. The About text on the project is still gecko’s to rewrite. These notes do not replace that.

## Install

Keep scrolling for the zip under **Assets**. Download `twitch-adblock-0.2.12.zip`. Unzip it and load that folder in Chrome the same way as the stable build. You do not need the long picture guide again. This replaces the 0.2.11 beta. v0.2.3 stays the stable download.

Do not replace your stable v0.2.3 folder if you want the main download unchanged. This beta is a separate folder.
